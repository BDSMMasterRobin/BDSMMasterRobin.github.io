ℹ️ Firebase Sync - Help & Guide

Important Info:
  • Only ONE person (e.g. Dom) needs a Google account to set up the Firebase project once.
  • The second person (Sub/Partner) needs NO Google account, they simply use the generated join code.

1. Create Firebase Project (Person 1)

  1. Go to console.firebase.google.com (free Google account).
  2. Click "Create Project" or "Add Project" (e.g. name "habits-app").
  3. In project overview, click the web icon (</>) to add a web app.
  4. Enter an app name (no need to check "Firebase Hosting") and click "Register App".
  5. At "Add Firebase SDK" step, copy only the content inside curly braces at const firebaseConfig = { ... }; into the Firebase Config field.

2. Enable Realtime Database

  1. In the left menu, select Build > Realtime Database and click "Create Database".
  2. Choose location, keep test mode or create database, and switch to the Rules tab.
  3. Replace rules with the provided JSON snippet and click "Publish".
{
  "rules": {
    "rooms": {
      "$roomId": {
        ".read": true,
        ".write": true
      }
    }
  }
}

3. Connect & Invite Partner

  1. Enter any Room ID (e.g. our-space-2026) and click Connect Firebase.
  2. Under Partner 1-Click Join Code, click Generate Code and send it to your partner.

4. Join (Person 2 / Partner)

  1. Open habits on partner's device.
  2. Go to Setup & Sync, paste join code below, and click Join Room.
