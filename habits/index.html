ℹ️ Firebase Sync - Hilfe & Anleitung

Wichtig / Wichtige Info:
  • Nur EINE Person (z. B. Dom) benötigt einen Google-Account, um das Firebase-Projekt einmalig einzurichten.
  • Die zweite Person (Sub/Partner) benötigt KEINEN Google-Account, sondern nutzt einfach den generierten Join-Code.

1. Firebase Projekt erstellen (Person 1)

  1. Gehe auf console.firebase.google.com (kostenloser Google-Account).
  2. Klicke auf "Projekt erstellen" oder "Projekt hinzufügen" (z. B. Name "habits-app").
  3. Klicke in der Projektübersicht auf das Web-Symbol (</>), um eine Web-App hinzuzufügen.
  4. Gib einen App-Namen ein (der Haken bei "Firebase Hosting" muss nicht gesetzt werden) und klicke auf "App registrieren".
  5. Beim Schritt "Firebase SDK hinzufügen" muss nicht der gesamte Code kopiert werden. Kopiere nur den Inhalt in den geschweiften Klammern bei const firebaseConfig = { ... }; (inklusive { und }) in das Feld Firebase Config (JSON).

2. Realtime Database aktivieren

  1. Wähle im linken Menü Erstellen / Build > Realtime Database und klicke auf "Datenbank erstellen".
  2. Wähle den Standort aus, behalte den Testmodus bei oder erstelle die Datenbank und wechsle zum Reiter Regeln (Rules).
  3. Ersetze die Regeln durch folgenden Code und klicke auf "Veröffentlichen" (Publish):
{
  "rules": {
    "rooms": {
      "$roomId": {
        ".read": true,
        ".write": true
      }
    }
  }
}

3. Verbindung herstellen & Partner einladen

  1. Gib eine beliebige Room ID ein (z. B. unser-raum-2026) und klicke auf Firebase Verbinden.
  2. Klicke unter Partner 1-Klick Join-Code auf Code Generieren und sende den Code an deine(n) Partner(in).

4. Beitreten (Person 2 / Partner)

  1. Öffne habits auf dem eigenen Gerät.
  2. Gehe zu Setup & Sync, füge den Join-Code unten ein und klicke auf Raum Beitreten.
